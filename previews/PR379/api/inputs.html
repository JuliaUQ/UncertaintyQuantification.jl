UncertaintyQuantification.Interval Type
julia
Interval(lb::Real, ub::Real)
Interval()

Represents a closed numeric interval with a lower bound lb and an upper bound ub. Interval() represents the empty interval, displayed as ∅. Intersections use ∩ (or intersect); use isempty to check whether an intersection is empty.

Interval is a data type primarily used for constructing probability boxes (p-boxes) and other uncertainty representations. It is not intended for direct use in simulations for that, see IntervalVariable.

Fields

  • lb::Real: Lower bound of the interval.

  • ub::Real: Upper bound of the interval.

Examples

julia
julia> Interval(0.1, 0.14)
[0.1, 0.14]

julia> Interval(0, 2) ∩ Interval(1, 3)
[1, 2]

julia> isempty(Interval(0, 1) ∩ Interval(2, 3))
true

UncertaintyQuantification.ProbabilityBox Type
julia
ProbabilityBox{T}(parameters::Dict{Symbol, Union{Real, Interval}}, lb::Real, ub::Real)

Concrete p-box for a univariate distribution family T, with precise (Real) or interval (Interval) distribution parameters and optional truncation. Subtype of AbstractProbabilityBox{T}. For a distribution-free p-box with explicit moment and range fields, use MomentProbabilityBox.

To use the ProbabilityBox in an analysis it has to be wrapped in a RandomVariable.

Fields

  • parameters::Dict{Symbol, Union{Real, Interval}}: Distribution parameter values or intervals.

  • lb::Real: Lower bound of the distribution's support.

  • ub::Real: Upper bound of the distribution's support.

Constructors

  • ProbabilityBox{T}(parameters::Dict{Symbol, Union{Real, Interval}}, lb::Real, ub::Real): Specify all parameters and support bounds explicitly.

  • ProbabilityBox{T}(parameters::Dict{Symbol, Union{Real, Interval}}): Support bounds are inferred from the distribution type T.

  • ProbabilityBox{T}(parameter::Interval): For univariate distributions with a single parameter, construct from a single interval.

For convenience the first two constructors can also be called with a Vector{Pair{Symbol,Union{Real,Interval}}} to automatically create the Dict.

The keyword constructor ProbabilityBox(; mean=nothing, var=nothing, lb=-Inf, ub=Inf, range=nothing) is a convenience constructor for MomentProbabilityBox.

Examples

julia
julia> ProbabilityBox{Normal}(Dict(:μ => Interval(0, 1), :σ => Interval(0.1, 1)), 0.0, Inf)
ProbabilityBox{Normal}(Dict{Symbol, Union{Real, Interval}}(:μ => [0, 1], :σ => [0.1, 1]), 0.0, Inf)

julia> ProbabilityBox{Normal}(Dict(:μ => Interval(0, 1), :σ => Interval(0.1, 1)))
ProbabilityBox{Normal}(Dict{Symbol, Union{Real, Interval}}(:μ => [0, 1], :σ => [0.1, 1]), -Inf, Inf)

julia> ProbabilityBox{Exponential}(Interval(0.1, 0.5))
ProbabilityBox{Exponential}(Dict{Symbol, Union{Real, Interval}}(:θ => [0.1, 0.5]), 0.0, Inf)

julia> ProbabilityBox{Normal}([:μ => Interval(0, 1), :σ => Interval(0.1, 1)])
ProbabilityBox{Normal}(Dict{Symbol, Union{Real, Interval}}(:μ => [0, 1], :σ => [0.1, 1]), -Inf, Inf)

UncertaintyQuantification.MomentProbabilityBox Type
julia
MomentProbabilityBox(; mean = nothing, var = nothing, lb = -Inf, ub = Inf, range = nothing)
ProbabilityBox(; mean = nothing, var = nothing, lb = -Inf, ub = Inf, range = nothing)

Construct a distribution-free p-box from moment constraints and/or support bounds. Return a MomentProbabilityBox, a concrete subtype of AbstractProbabilityBox{MomentConstraints} with explicit mean, var and range fields. mean and var accept a Real or an Interval; var is the population variance, not the standard deviation. An omitted variance is unknown. An omitted mean requires finite support bounds and is inferred from the support and variance constraints. Omitting both moments gives a range-only p-box. range=Interval(a, b) is shorthand for lb=a, ub=b.

Fields

  • mean::Interval: Mean values; a precise input becomes a point interval.

  • var::Interval: Variances; a precise input becomes a point interval.

  • range::Interval: Support bounds, which may have infinite endpoints.

Bound construction and selection

Constructions follow Sections 6.1–6.3 of Gray et al. (2022):

Available informationP-box boundsConstruction
Mean + variance, unbounded supportOne-sided ChebyshevMean–variance tail inequalities.
Mean + lower or upper boundMarkovApply Markov to X-lb or ub-X.
Mean + finite range, unknown varianceMarkov from both endpointsIntersect the shifted and reflected Markov bounds.
Mean + variance + one support endpointCantelli construction in Gray et al.Combine one-sided Chebyshev and Markov using the known endpoint (Section 6.2).
Mean + variance + finite rangeMin–max–mean–varianceOptimize the bounded moment constraints (Section 6.3).
Variance + finite range, unknown meanMin–max–mean–varianceEnvelope the bounds over all feasible means inferred from the range and variance.
Finite range onlyRange envelopeAll distributions supported within the range remain possible.

Feasibility and interval moments

Moment intervals describe all feasible moment values within the intervals. They are intersected with the support's theoretical moment bounds; inconsistent constraints throw ArgumentError. CDF and quantile bounds envelope all feasible distributions, including discrete distributions. The envelopes can also contain distributions that do not satisfy the original moment constraints.

Wrap the result in RandomVariable for sampling and RandomSlicing. Parametric DoubleLoop analysis is not supported.

Check check_moments_and_range for how feasibility constraints are computed

References

  • Chebyshev, Des valeurs moyennes (1867), pp. 177–184: the classical two-sided inequality.

  • Chebyshev, Sur les valeurs limites des intégrales (1874), pp. 159–160: piecewise bounds from range, mean and variance; their unbounded-support limits give the one-sided mean–variance bounds.

  • Markoff, Sur une question de maximum et de minimum proposée par M. Tchebycheff (1886), Acta Mathematica 9, pp. 57–70: historical background on the general moment-bounds problem. See markov_cdf for the elementary inequality used here and its derivation.

  • Cantelli, Sui confini della probabilità, proceedings of the 1928 Bologna congress (published 1932), vol. 6, pp. 47–59: Section 7, p. 53, equations (19) and (21) give the one-sided mean–variance bounds.

  • Gray, Ferson, Kreinovich and Patelli, Distribution-free risk analysis (2022), Section 6: p-box constructions followed here, with CDF orientation and quantiles treated explicitly.

Examples

julia
ProbabilityBox(; mean = 0, var = 1)                 # Chebyshev
ProbabilityBox(; mean = 2, range = Interval(0, 5))  # Markov from both endpoints
ProbabilityBox(; mean = 2, lb = 0)                 # shifted Markov
ProbabilityBox(; mean = 2, ub = 5)                 # reflected Markov
ProbabilityBox(; mean = 0, var = 3, lb = -1)        # Cantelli
ProbabilityBox(; mean = 0, var = 1, ub = 2)         # reflected Cantelli
ProbabilityBox(; mean = Interval(1, 2), var = Interval(0.2, 1), range = Interval(0, 5))
ProbabilityBox(; var = Interval(0.2, 1), range = Interval(0, 5))
ProbabilityBox(; range = Interval(0, 5))           # range only
MomentProbabilityBox(; mean = 0, var = 1)          # direct constructor

UncertaintyQuantification.check_moments_and_range Function
julia
check_moments_and_range(; mean = nothing, var = nothing, lb = -Inf, ub = Inf)

Check consistency and tighten moment information using theoretical bounds implied by the support. Return (mean_interval, variance_interval, lb, ub).

For example, for a range = [a, b], is impossible to have:

mean ∩ [a, b] = ∅ var ∩ [0, (b-a)^2/4] = ∅

We may thus check that these intersections are non-empty, but also tightened intervals. If the mean and variance are known, their theoretical bounds are returned. An empty intersection is impossible and throws ArgumentError; for example, mean=Interval(3, 4) cannot be consistent with lb=0, ub=2.

An omitted mean requires finite support bounds and starts as the full range. An omitted variance starts as [0, Inf] and requires at least one finite support bound.

For finite support [a, b], feasible moments satisfy v ≤ (m-a)*(b-m). With no mean information this gives [0, (b-a)^2/4], whose upper bound is attained by equal probability masses at the two endpoints (the maximum variance of an interval). A specified mean can give a smaller upper bound, attained by suitable endpoint probabilities. Evaluate this quadratic at both mean endpoints and at the range midpoint a + (b-a)/2 when it belongs to the mean interval. Intersect the supplied variance with [0, max(v1, v2, v3)]. As an extra tightening step, solving (m-a)*(b-m) ≥ variance_interval.lb tightens the mean interval. An exactly known mean at a finite support endpoint forces zero variance. Inconsistent joint constraints also throw ArgumentError.

UncertaintyQuantification.chebyshev_cdf Function
julia
chebyshev_cdf(x, mean, var)

Return the interval CDF bound from the Chebyshev inequality using a precise or interval mean and variance on unbounded support. For t > 0, use P(X-mean ≥ t) ≤ var/(var+t^2) and its reflection. Only the mean and variance are required. This is the one-sided refinement of the classical two-sided inequality P(abs(X-mean) ≥ t) ≤ var/t^2.

The one-sided formula follows by taking unbounded-support limits in Chebyshev (1874), pp. 159–160. It is also known as Chebyshev–Cantelli or Cantelli's inequality; an explicit later statement is in Cantelli's Sui confini della probabilità, Section 7, p. 53, equations (19) and (21), in the 1928 Bologna congress proceedings (vol. 6, published 1932).

Moment constraints must be consistent; see check_moments_and_range.

UncertaintyQuantification.cantelli_cdf Function
julia
cantelli_cdf(x, mean, var, lb, ub)

Return the combined p-box construction called Cantelli bounds in Section 6.2, equations (37)–(38), of Gray et al. (2022): combine the chebyshev_cdf mean–variance bounds with shifted/reflected markov_cdf bounds. One support endpoint is known; use -Inf or Inf for the other. Moment and support constraints must be consistent. With two finite endpoints, meanvarminmax_cdf uses their full joint moment constraints. The construction's name follows Gray et al. The one-sided Chebyshev inequality it uses is itself also called Cantelli's inequality and needs only mean and variance; see chebyshev_cdf for its formula and historical sources.

UncertaintyQuantification.cantelli_quantile Function
julia
cantelli_quantile(u, mean, var, lb, ub)

Return the explicit inverse Cantelli bounds of Section 6.2 of Gray et al. (2022) for consistent mean, variance and one known support endpoint. Use -Inf or Inf for the unknown endpoint. Combine the Chebyshev and Markov inverses for 0 < u < 1; at endpoint probabilities, also use the variance lower bound to constrain the possible essential infimum/supremum. See cantelli_cdf for the source and naming convention.

source
UncertaintyQuantification.markov_cdf Function
julia
markov_cdf(x, mean, lb, ub)

Return shifted/reflected Markov CDF bounds from a precise or interval mean and support endpoints. Either endpoint may be infinite. Moment and support constraints must be consistent; see check_moments_and_range.

Apply P(Y ≥ y) ≤ E[Y]/y for y > 0 to the nonnegative variable Y=X-lb or Y=ub-X. The inequality follows directly from y*1{Y ≥ y} ≤ Y by taking expectations. For background on the general moment-bounds problem, see Markoff (1886), Acta Mathematica 9, pp. 57–70.

UncertaintyQuantification.meanvarminmax_cdf Function
julia
meanvarminmax_cdf(x, mean, var, lb, ub)

Return the mean–variance–minimum–maximum CDF bounds described in Section 6.3 of Gray et al. (2022). Precise and interval moments are supported, and with an infinite endpoint, reduce to cantelli_cdf. Inputs must satisfy check_moments_and_range.

source
UncertaintyQuantification.meanvarminmax_quantile Function
julia
meanvarminmax_quantile(u, mean, var, lb, ub)

Return explicit quantile bounds at probability u ∈ [0, 1] for checked moment and support constraints.

For interval moments, envelope over the feasible mean endpoints, their one-sided limits and an analytic interior extremum. With an infinite endpoint, reduce to cantelli_quantile. Endpoint probabilities, zero variance and forced endpoint atoms have explicit handling, including variance lower bounds. See meanvarminmax_cdf for the corresponding CDF bounds and their sources.
