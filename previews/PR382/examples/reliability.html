Adaptive Gaussian Process Monte Carlo simulation ​

This method estimates the probability of failure of a performance function by building a Gaussian process (GP) surrogate from an initial design and iteratively enriching it with one point at a time, chosen from a set of candidate samples by an acquisition function, until the stopping criterion or the sample budget is reached. It is also known in literature as AK-MCS (Adaptive Kriging Monte Carlo Simulation).

Example 1 from Echard et al. (2011) ​

We consider the following series system of perfomance functions, as in Example 1 of Echard et al. (2011):

G(x1,x2)=min{3+0.1(x1−x2)2−x1+x22;3+0.1(x1−x2)2+x1+x22;(x1−x2)+k2;(x2−x1)+k2}

where k=6.0 or k=7.0 usually. The input random variables are independent and normally distributed, with x1,x2∼N(0,1).

First, define the probabilistic input and the series of performances.

julia
x = RandomVariable.(Normal(), [:x1, :x2])

k = 6.0
g1 = Model(df -> 3 .+ 0.1 * (df.x1 .- df.x2) .^ 2 .- (df.x1 .+ df.x2) ./ sqrt(2), :g1)
g2 = Model(df -> 3 .+ 0.1 * (df.x1 .- df.x2) .^ 2 .+ (df.x1 .+ df.x2) ./ sqrt(2), :g2)
g3 = Model(df -> (df.x1 .- df.x2) .+ k / sqrt(2), :g3)
g4 = Model(df -> (df.x2 .- df.x1) .+ k / sqrt(2), :g4)
models = [g1, g2, g3, g4]
g = df -> min.(df.g1, df.g2, df.g3, df.g4)

We now construct the adaptive Gaussian process Monte Carlo simulation. We use a small number of initial samples to initially train the GP surrogate. The initial samples are generated using a quasi-Monte Carlo method. Very few samples are needed to initially train the GP surrogate. The acquisition function is set to DeviationNumber(), which selects the next point to evaluate based on the deviation number, i.e., the points with a high potential risk of crossing the predicted separator limit state function, approximated by GP. The enrichment stops when the deviation number is below a threshold of 2.0, or when the maximum number of samples is reached. The GP surrogate is fitted with a constant mean function and a squared exponential kernel, and the hyperparameters are optimized after each enrichment.

julia
optim = MaximumLikelihoodEstimation(Optim.Adam(alpha = 0.005), Optim.Options(; iterations = 10, show_trace = false))
akmcs = AdaptiveGaussianProcessMonteCarlo(
    1_000_000,
    QuasiMonteCarloSampling(10, LatinHypercubeSample()),
    DeviationNumber(),
    2.0,
    200;
    optimizer = optim
)

Next, we run the simulation and estimate the probability of failure. The result is the estimated probability of failure, the standard deviation of the estimate, the samples evalauted, and the fitted GP surrogate. The fitted GP surrogate can be used to visualize the limit state function and the uncertainty of the prediction.

julia
pf_akmcs, std_akmcs, samples_akmcs, adaptive_gp = probability_of_failure([g1, g2, g3, g4], g, x, akmcs)

Finally, we visualize the limit state function. We will also plot the GP approximation of the limit state function, and the samples evaluated by the adaptive GP Monte Carlo simulation. We also compare the results with a standard Monte Carlo simulation with 1 million samples.

julia
mc = MonteCarlo(1.0e6)

pf_mc, std_mc, samples = probability_of_failure(models, g, x, mc)

lsf(x, y) = minimum(
    [
        3 + 0.1 * (x - y)^2 - (x + y) / sqrt(2),
        3 + 0.1 * (x - y)^2 + (x + y) / sqrt(2),
        (x - y) + k / sqrt(2),
        (y - x) + k / sqrt(2),
    ]
)

function lsf_GP_adapt(x, y)
    df = DataFrame([:x1, :x2] .=> [x, y])
    evaluate!(adaptive_gp, df)
    return only(df.g_mean)
end

implicit_plot(lsf; xlims = (-8, 8), ylims = (-8, 8), linecolor = :gray)
implicit_plot!(lsf_GP_adapt; xlims = (-8, 8), ylims = (-8, 8), linecolor = :black)
scatter!(adaptive_gp.gp.data.x1, adaptive_gp.gp.data.x2)

Finally, the probability of failure estimates are printed.

julia
println("Probability of failure (Adaptive GP):  $pf_akmcs ± $std_akmcs")
println("Probability of failure (Standard MC):  $pf_mc ± $std_mc")
Probability of failure (Adaptive GP):  0.004471 ± 6.671589135281038e-5
Probability of failure (Standard MC):  0.004476 ± 6.67530180890722e-5
